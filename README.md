# Sleepvia Full-Stack Sample App

Sleepvia is a reference full-stack application demonstrating a modern web architecture with a React frontend and a Java Spring Boot backend.

The project includes:

- `frontend/` — a React single-page application
- `backend/` — a Spring Boot REST API
- `k8s/` — Kubernetes manifests for deploying the frontend and backend

This repository is intended as a practical example of how to structure a cloud-native web application with containerized services and deployment manifests.
